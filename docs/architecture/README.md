# Архитектура DashSpec — артефакты

Эта папка содержит материалы к документу **[../ARCHITECTURE_RU.md](../ARCHITECTURE_RU.md)**.

| Файл | Назначение |
|------|------------|
| `DashSpec-Architecture-RU.docx` | Версия документа для Word: диаграммы вставлены как изображения, оглавление — нативное |
| `diagrams/*.mmd` | **Источник истины** диаграмм на языке Mermaid |
| `diagrams/mermaid-config.json` | Настройки вёрстки (ширина переноса подписей, шрифт) |
| `diagrams/*.svg` | Векторная версия (для чтения в браузере, IDE, GitHub) |
| `diagrams/*.png` | Растровая версия с двойным масштабом (для DOCX и презентаций) |
| `render-diagrams.py` | Пересборка: Mermaid → SVG → PNG |
| `make-docx.ps1` | Пересборка: Markdown → DOCX + оглавление Word |

## Пересборка

```powershell
# Диаграммы: нужен mermaid-cli (npm install -g @mermaid-js/mermaid-cli)
# либо, как запасной путь, Chrome/Edge и доступ в интернет
python docs/architecture/render-diagrams.py

# Документ Word: нужен pandoc (https://pandoc.org); Word — для оглавления
pwsh -File docs/architecture/make-docx.ps1
```

Правьте **только `.mmd`** и пересобирайте изображения скриптом — иначе SVG и PNG разойдутся с исходником.

## Требования к диаграммам

Чтобы картинка целиком помещалась на страницу Word и оставалась читаемой, соблюдайте два правила:

1. **Соотношение сторон** (ширина / высота) не меньше **0,7** — иначе изображение не влезет по высоте.
2. **Число шагов в цепочке не больше шести** на одну диаграмму — длинные цепочки рисуются узкой высокой колонкой. Длинный конвейер лучше разбить на 5a и 5b, как это сделано для конвейера компиляции.

Проверить можно так: скрипт печатает размеры, а в `render-diagrams.py` есть формула расчёта рекомендуемой ширины.
