# Заметка: CDP — агентский авторинг DashSpec

Идея (оператор, 2026-10-21): в CDP добавить полную поддержку DashSpec —
агентский авторинг. Спека машинно-friendly (модули, типы, флоу, GDL-таблицы),
агенту проще авторить её, чем человеку тыкать в GUI.

Что это сняло бы (по опыту текущих сессий):

- LSP-навигация по модулям (jump-to-definition: `diagram ref` → файл диаграммы,
  `import flows from X` → файл флоу, типы → строки).
- Диагностика парса на лету (ошибки валидации — token/ref/flow — прямо в
  буфере, без цикла «правка → хост → reload → страница»).
- Автодополнение словарей (vocabulary constructs: columns/filter views/click
  table; schemas: tableDiagram, presentation).
- Прогон спеки из CDP (parse + compile + render через dev-хост, отчёт об
  ошибках в evidence).

Открыто: не ADR — направление. Когда нагрузка на авторинг спеки станет
регулярной (LUS-корпус растёт), оформить как ADR с прицелом на слой Modeling
(CDP уже умеет F#-проекты).
