# Заметка: CDP — агентский авторинг DashSpec

Идея (оператор, 2026-10-21): в CDP добавить полную поддержку DashSpec —
агентский авторинг. Спека машинно-friendly (модули, типы, флоу, GDL-таблицы),
агенту проще авторить её, чем человеку тыкать в GUI.

**Статус: основа реализована и развёрнута (2026-10-21, dash-spec d70d891 + guiders-fsharp aa02ee7, CdpService redeployed):**

- Живой язык — `.ds` (легаси-семейство `.dash*` убрано из PathRules).
- Воркспейс-индекс: все виды модулей (`module <kind> <id>`) + неймспейсы
  → файл + строка объявления.
- Go-to-definition по корпусу: `diagram ref <slot> <id>`, `use flow <id>`,
  `import <kind> from <Namespace>` → файл объявляющего модуля;
  карточки/фильтры/вкладки — локально (токен-индекс).
- Find-usages по корпусу для ид модулей (вхождения + цель-объявление).
- Токен-аутлайн для файлов модулей (диаграммы/флоу/презентации).
- Автодополнение: живые формы `diagram ref <slot> <id>` и `use flow <id>`
  (ид из воркспейс-индекса).

**Проверено E2E на развёрнутом CdpService (LUS-корпус):**

- `.ds` → язык `dashspec` (буферная плоскость).
- Диагностика нашла реальную ошибку спеки (заимствованный app_name
  ломал одиночный парс вкладки) → SSOT-фикс (своё объявление + слияние
  идентичных фильтров во встроенном парсе) → чисто.
- Автодополнение ид диаграмм на `diagram ref products <…>` ✓.

**Хвост 2-й заход (2026-10-21, тот же день) — закрыто:**

- GoToAll (Ctrl+T / `cdp_graphql goto`): FTS-дефолты индексируют `.ds`
  (guiders-core c99f396) — goto приземляется на объявление модуля
  диаграммы (топ-хит `app-list-table.ds:1` на запрос
  `lus_users_app_list_table`). Индекс пересобран, `.hybrid-codebase-index/`
  добавлен в .gitignore.
- Кэш-инвалидация диагностики буфера (cdp-mcp c1fdc69b): чистый буфер
  с дрейфом диска перечитывает диск перед read/diagnostics (VS Reload);
  dirty держит память, `keep_disk` уважается. Проверено живьём:
  внешняя правка → диагностика без close+open приносит свежую ошибку.

**Хвост 3-й заход (2026-10-21, dash-spec 13a8d82) — диагностика видит как рантайм:**

- Вкладка валидируется так, как её собирает рантайм: каждый импортирующий
  корень собирает её (merge + валидация графа через DashboardValidationCollector
  + ResolutionLint), атрибуция — по рёбрам самого графа (ModulePath + CardIds).
  Корневой dashboard-файл — с merge ON. Сирота (никто не импортирует) —
  одиночный парс + warning «not imported by any root». Несохранённый
  буфер — одиночная обратная связь до flush.
- Кэш собранного корпуса — паттерн FcsCompilerServicesHost (готовая модель
  CDP/Federation): материализация раз на ревизию корпуса, ревизия = mtime
  членов (членство dsproj через компиляторный UnitIndex.corpusFiles),
  корни компилируются лениво и живут в кэше до изменения любого члена —
  «файл не менялся — не перекомпилируем». UnitIndex: экспонирован corpusFiles
  (без stdlib — он едет с продуктом, не по mtime процесса).
- Проверено живьём на LUS-корпусе: дифференциал — временное удаление
  собственного `app_name` из юзер-вкладки (заимствованное состояние,
  одиночный парс падает «more than one flow input») → диагностика чистая
  (встроенный вид), строка возвращена байт-в-байт. Соук теперь честно
  несёт DS0571-warning'и собранного документа (merge ON).
- Честная находка: готовая модель под кэш — федеральный принцип
  ревизионно-стабильной модели (суверенные планеты, общий протокол:
  materialize-once/стейл-по-ревизии — экземпляры FcsCompilerServicesHost,
  revision bus Code Center) — его экземпляр и построен на территории
  DashSpec. Сессионный граф (sibling-продукт 0062) — отдельная опция для
  .ds-документов (DocumentRegistry/SurfaceVersion), диагностике не нужна:
  вторая параллельная материализация рядом с хостом.

**Хвосты (следующие шаги):**

- Ремонт моста MCP (CDP_RELOAD_NUDGE): мост (CdpMcpBridge) остаётся
  тонким транспортом, инструменты работают; свежий мост ставится когда
  мосты не запущены (apply при погашенных сессиях). LRC-глаголы
  go_to_definition/find_usages остаются вне tools/list (ADR-0233
  collapse) — CallTool-диспетчеризация в сервисе, из opencode-места
  доступна через `cdp_graphql goto`/`symbol`.
- Автодополнение словарей: views/columns-таблицы, click-table
  vocabulary — сейчас keywords + module ids.
- Federation-принцип в реализации DashSpec (конституция: суверенные
  планеты, общие протоколы, без аннексии): DashSpec уже в федерации
  через LRC-гиперлейн (адаптер AIGuiders.Platform.Modeling.Language).
  Хвост — следовать общему принципу ревизионно-стабильной модели дальше
  (образец — revision bus Code Center, GUIDERS-ADR-0066): событийная
  ревизия корпуса (мутация → revision++ → поверхности обновляются)
  вместо дисковой mtime; документ-сессия `.ds` с поверхностями
  (text есть; tree/diagram — будущее). Центральной «регистрации в
  федерацию» не существует — только протоколы.
- Виртуальные тексты в парсе (override текстов буфера при сборке) —
  сейчас несохранённый буфер вкладки получает одиночную обратную связь,
  встроенный вид применяется к сохранённому состоянию.
